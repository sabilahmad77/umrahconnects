## Decision sequence

First resolve product facts for roles, scope, pricing basis, supported payment paths and marketing proof. Then establish navigation/mobile/dialog foundations and role task hierarchy. Apply the selected visual character after those contracts are coherent. Do not spend redesign effort treating incorrect state/claims as a palette problem.

Every proposed queue, readiness score, live status, bulk action, filter and checkout step needs supported data and permissions. No source or production state was corrected during this discovery.
