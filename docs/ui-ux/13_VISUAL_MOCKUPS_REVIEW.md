# Umrah Connect — A/B/C visual mockups

Twelve generated desktop concepts. Design review only; no application implementation. Generated with the built-in image-generation tool from the three saved image prompt packs.

All destination imagery is AI-generated and illustrative. These mockups use a plain-text wordmark placeholder; the existing production logo remains authoritative. Unavailable metrics and illustrative empty lists are intentional.

## Review notes

Use these images to compare direction, hierarchy and density. They are raster interpretations, not pixel-exact implementation specifications. The generator introduced small copy/icon/font variations and changed some sidebar treatments. The source direction documents govern final design decisions. Direction C landing has a “Marketplaces” label variation and omitted its in-image concept caption; this page explicitly labels it illustrative. Direction B landing contains a minor table-header text artifact. Final approved copy, logo, typography, spacing and accessibility need precise treatment after direction selection.

Direction B landing is a taller composition; compare its hero at the same display width as A/C. No direction has been selected.
